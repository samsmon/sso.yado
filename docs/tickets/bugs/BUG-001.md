# BUG-001 - Guard `api` undefined in `config/auth.php`

**Severity**: P0 - Blocker (GET /api/user always returns 500)
**Status**: Fixed
**Found during**: Runtime verification session 2026-07-21

## Symptom

```
GET /api/user HTTP/500
{"message": "Auth guard [api] is not defined."}
```

## Root Cause

`config/auth.php` only defined the `web` guard. The `GET /api/user` route uses the `auth:api` middleware, but the `api` guard was missing.

## Fix Applied

Added the `api` guard to `config/auth.php`:

```php
'api' => [
    'driver' => 'passport',
    'provider' => 'users',
],
```

**File**: `config/auth.php` — fixed in this session.
