# BUG-002 - Middleware alias `scope` points to non-existent class in Passport 13

**Severity**: P0 - Blocker (GET /api/user with valid token always returns 500)
**Status**: Fixed
**Found during**: Runtime verification session 2026-07-21

## Symptom

```
GET /api/user HTTP/500
{"message": "Target class [Laravel\Passport\Http\Middleware\CheckForAnyScope] does not exist."}
```

## Root Cause

`bootstrap/app.php` registered the alias `scope` to `CheckForAnyScope` and `scopes` to `CheckScopes`. In Passport 13.x, both classes do not exist — replaced by `CheckTokenForAnyScope`.

## Fix Applied

Updated `bootstrap/app.php`:

```php
// Before
'scope'  => \Laravel\Passport\Http\Middleware\CheckForAnyScope::class,
'scopes' => \Laravel\Passport\Http\Middleware\CheckScopes::class,

// After
'scope'  => \Laravel\Passport\Http\Middleware\CheckTokenForAnyScope::class,
'scopes' => \Laravel\Passport\Http\Middleware\CheckTokenForAnyScope::class,
```

**File**: `bootstrap/app.php` — fixed in this session.
